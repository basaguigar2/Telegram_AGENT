# Prompt - Auditoría Arquitectónica JARVIS

Actúa como un CTO especializado en arquitectura de sistemas de IA, agentes autónomos y diseño de organizaciones digitales.

No quiero que actúes como asistente conversacional.

Quiero una auditoría crítica de una arquitectura llamada JARVIS.

## Contexto

JARVIS es un Sistema Operativo Cognitivo Personal y Empresarial.

El objetivo no es crear un chatbot.

El objetivo es construir una infraestructura personal capaz de gestionar conocimiento, organizar la vida del usuario, coordinar agentes especializados y ayudar en decisiones estratégicas.

Principios fundamentales:

- La memoria es más importante que el modelo de IA.
- Los modelos son intercambiables.
- Debe existir una única fuente de verdad.
- El usuario mantiene el control estratégico.
- Los agentes son trabajadores especializados.
- La IA debe utilizarse de forma eficiente.

## Tu misión

Realiza una auditoría completa.

Analiza:

# 1. Arquitectura

¿La separación de responsabilidades es correcta?

¿Hay módulos mal definidos?

¿Existe acoplamiento innecesario?

¿Qué cambiarías?

---

# 2. Escalabilidad

Evalúa si esta arquitectura podría crecer durante 5-10 años.

¿Funcionaría con cientos de agentes?

¿Funcionaría con diferentes modelos de IA?

---

# 3. Riesgos

Identifica:

- Errores de diseño.
- Sobreingeniería.
- Complejidad innecesaria.
- Puntos únicos de fallo.
- Decisiones peligrosas.

---

# 4. Comparación

Compara esta arquitectura con:

- Sistemas multiagente modernos.
- Arquitecturas empresariales.
- Sistemas de gestión del conocimiento.
- Sistemas operativos personales.

---

# 5. Recomendaciones

Propón:

- Cambios obligatorios.
- Cambios recomendados.
- Cambios opcionales.

No añadas complejidad si no aporta valor.

---

# 6. Opinión final

Responde:

¿Tiene sentido construir esto?

¿Qué eliminarías?

¿Qué mantendrías?

¿Qué construirías primero?

Sé crítico.

Si una idea es mala, dilo claramente.

Si falta algo importante, identifícalo.

Tu objetivo no es validar la idea.

Tu objetivo es mejorarla.
